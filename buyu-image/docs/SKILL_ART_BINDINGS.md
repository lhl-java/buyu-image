# 六技能美术绑定

正式六项以08技能界面为准：冰封、雷网、聚鱼、追踪、护持、激流。机器入口为 `config/skill-art-bindings.json`。

| 技能 | 图标 | 效果与状态 |
|---|---|---|
| 冰封 | skills/skill-ice | fx-ice，目标中心单次释放；减速时长由客户端控制 |
| 雷网 | skills/skill-thunder | fx-thunder，目标中心单次播放 |
| 聚鱼 | skills/skill-gather | fx-gather，吸引中心单次金流；图内金鱼光纹不是生物动作 |
| 追踪 | skills/skill-track | ornaments/aim-gold跟随目标根点，固定尺寸，仅透明度轻脉冲 |
| 护持 | skills/skill-guard | fx-guard单次释放；候选第7帧独立持续叠层，状态结束后移除，不能循环消散帧 |
| 激流 | skills/skill-surge | fx-surge，目标区域单次蓝白浪 |

所有FX使用固定原生帧注册，不按各帧透明包围框重置位置。需要留白而原形/光尾完整时，可以给全组补同样宽度透明边；逐图记录原生格尺寸、补边和根点变换，不把补边尺寸写成新生成细节。原表留白未达标的告警保留，运行留白与源图门禁分别报告。已截断或跨格混入的轮廓必须修正原图，不能靠补边掩盖。

技能冷却、保护状态、鱼体受击/游动、吸引轨迹和数值仍由游戏逻辑或独立动作处理。绑定数据和静态峰值图层不证明正式客户端的时序、重叠、可读性与性能已经通过。
