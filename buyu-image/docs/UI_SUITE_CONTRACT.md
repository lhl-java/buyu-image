# 捕鱼 UI 全套制作合同

2026-10-26 用户要求“继续做完所有UI”。本轮补齐 31 项美术设计交付：现有捕鱼主界面复用，新增 30 张界面或状态图。具体逐项清单唯一维护于 [UI_SUITE_20261026.json](UI_SUITE_20261026.json)。清单中数字、角色名、道具属性与功能为演示文案，后续业务规则可替换。

所有屏幕沿用 image 已确认邮件／组队原图和本项目捕鱼主界面的道家 Q 版高清手绘，采用横屏约 16:9；实际原生像素以工具输出及逐图记录为准。两张主参考必须实际查看、实际附入每次调用；再附当前主界面作为捕鱼题材连续性参考。同功能参考存在时实际查看。人物页面另可附当前捕鱼道童。

新增图保存到 `designs/ui/full-suite-v1/<编号-名称>/`，各自保存原生 PNG、实际提示词、实际工具请求 JSON、原始工具返回文字与 generation.json。每次生成前重读根 AGENTS、配置与模型策略；内置工具没有 model/quality 选择器时照常继续，实际未知字段为 null。只使用内置入口。

文字须短而可读，严格采用清单要求的捕鱼文案，不能照搬参考图中的旧游戏名称、姓名与测试数据。每个界面明确标题、关闭／返回、主要操作、信息层级和选中状态；通用状态图补齐空白、加载、异常、确认和控件状态。仅在已有输出发生明确缺字、裁切或功能布局错误时定点修订，不无故多生变体。

并行职责：以逐项清单 owner 为准。A 已完成 01–04，B 已完成 06–08，C 已完成 13–14 并生成 15 初稿；其余由协调者完成或接续。剩余 09、16–18 在核对没有已选源和目标文件、停止等待中的 worker 后由协调者生成。各 worker 仅写自己编号目录；共享清单、配置和图集由协调者维护。

完成标准：31 项均可从图集打开；新增图片有真实文件、原生尺寸、哈希、配置快照、提交参数、实际版本证据、提示词与参考用途；每张经过目视检查，缺陷明确登记。设计集完成与正式切片／客户端实现分别报告。本轮是整套 UI 美术设计及状态规范，未提供客户端项目，因此不将其表述为可运行客户端或全部切片已接入。
