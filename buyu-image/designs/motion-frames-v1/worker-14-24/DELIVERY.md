# 13–24 号鱼：双动作候选交付

12种鱼，各有 swim / capture 两动作，共 **24套源图、192张运行时PNG**。13 capture 已包含。采用源版本由 `adopted-sources.json` 唯一列出；逐套明细、来源和指标见 `group-qa.json`。

全部源图为内置图像工具生成的原生1774×887、4×2、8相位RGBA表，保留逐次 prompt / request / receipt / generation 记录。工具未披露实际模型或质量，来源记录的实际值保持null；不能用配置目标证明实际型号。master静态素材保持原样。

运行时目录为 `assets/animations/<fish-id>/<swim|capture>/`。每套含 `frame-00.png` 至 `frame-07.png`、8份派生记录及 `manifest.json`。当前画布统一844×844，逻辑root为 `[422,422]`。鱼眼注册点 `[590,350]`；14幻月水母使用伞顶解剖近似点 `[470,250]`。root是同一逻辑坐标，不代表已消除生成的核心形变。

13云纹龟与14幻月的swim为8fps，各125ms；其他swim及全部capture为12fps，毫秒时长 `[83,84,83,83,84,83,83,84]`。swim循环，capture单次，顺序源表row-major 0–7，没有复制首帧作为末帧。每个物种使用一次从swim静息帧测得的 `uniformDisplayScale`，同鱼的swim与capture共用；接入不得每帧按bbox重新fit。

提取以8个分离的alpha>16解剖主体分配source像素ownership，保留每个alpha>3像素的原生RGBA，仅alpha≤3清零。只有名义格线越界、完整姿态仍在总图内且独立的情况，才用完整自定义sourceRect无损提取。整数平移和透明补边没有像素缩放、旋转、插帧或上采样。每帧元数据记录sourceRect、source点、整数offset和原生像素回取结果。本组alpha>3像素无丢失、无重复；这项技术结果不能作为动作或身份通过的证据。

已实际查看24套源图及各套当前浅深底注册联系表，共48张。可见尾柄、鳍、触手、龟鳍肢或花瓣尾的分相位变化；导出未见截断尾端、相邻帧残块或实色矩形背景。20 / 21 / 24 号固定脸部ROI已避开暗色斑纹与鳍片，重新整数注册后复看。原始view_image可能显示alpha0内残留RGB，透明质量以实际alpha合成联系表为准。

当前技术统计：运行时最小透明边距约 **15.7583%**，192帧无运行时12%边距警告；主体触及整张源图外边界警告0项。源图仍有 **35项名义格线越界警告、191项源格留白不足警告**，全部保留。透明补边只通过导出边距，不回填源图生产合格。

所有24套仍为 **producer_candidate_pending_root_registered_review**，`finalArtApproval=false`。尚需Unity逐套播放和协调者终审：

- 13 swim的3→4伸展转回桨、7→0闭环较急，头颈/甲壳仍有细微变化。
- 14伞体脉冲与近似伞顶注册仍需区分解剖运动和相机尺度变化。
- 15翼根/头部、16条纹/鳍刺、17珊瑚枝、18鳞纹/云纹、19红白边界、20斑纹、21金色须带、22莲瓣连接、23星纹、24硬甲/宝石轮廓仍需检查身份稳定性。
- 真实连播的节奏、闭环、capture与swim切换、同鱼跨动作尺度尚未验收。静态联系表和不同文件hash不能证明动画流畅。

本轮遵守重型作业HOLD，未启动测试、编译、服务、浏览器、atlas或Unity，没有操作全局目录、共享Git或上传。根协调者负责运行接入、播放验收、全局状态及发布。

当前可重建导出入口为 `register_group.py [fish-id ...]`，不传ID会处理本表12种。运行会刷新对应运行时图/manifest和联系表、重置候选实看标记；只有实际重新审看后才运行纯元数据脚本 `finalize_reviews.py`。`clip_export.py` 与13旧 `export_candidate.py` 已禁用，避免回写旧画布/旧帧率。`make_geometry_reference.py` 仅为生成时的静态构图参考，不是动画帧输出。
